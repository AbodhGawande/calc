How to use Calc

700
Just typeThe answer shows on the right as you go, slightly dimmed. Press = to finish the line: the answer turns solid and the next number starts a new line.
rent
Words name numbersA word right after a number names it: 700 rent + 500 food = 1,200, and now rent is 700. A word after = names the total: … = expense.
+
Several linesStart a line with + − × ÷ to carry on from the line above. The total shows on the last line. After an answer, pressing + − × ÷ does this for you.
✎
Edit anythingTap any number to put the cursor there and change it. Answers update straight away.
( )
BracketsAdd them anywhere. A missing ) is added for you.
700
Reuse an answerTap an orange answer: Use puts it on your line, Copy copies it.
rent
Use a nameOn any line below, type it or tap its blue chip above the keypad: rent×12. Change the original number and everything below updates. The same word used again further down takes over from there.
Name…
Name without the keyboardTap Name… above the keypad (or an answer's Name) to name the line you're on.
$₹
Dollars ⇄ rupeesPress $₹ to convert the line. Press it again to flip the direction.
ABC
WordsABC opens the iPhone keyboard for notes like “Hotel”. The orange calculator button brings the keypad back.
?
A grey ?That line can't be worked out. Check the brackets, and that its names are set on a line above.
↶
Undo and clear↶ undoes. The bin clears the page; ↶ brings it back until you close the app.
⤴︎
Back upThe share button saves a copy to Files. Do it now and then: iPhone can clear app data.

Backup

iPhone can clear a web app's saved data. Export saves a copy of the page to Files (e.g. iCloud Drive). Import adds a saved copy to the end of the page.
